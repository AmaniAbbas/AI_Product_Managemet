# AI Product Management Portfolio

This repository contains my projects completed while studying the Duke University AI Product Management Specialization on Coursera. The specialization focuses on machine learning fundamentals, managing machine learning projects, and designing human-centered AI products.

My goal is not only to understand how AI and machine learning systems work, but also how to lead, evaluate, and communicate AI product decisions as a Product Manager.

---

## About the Specialization

The Duke AI Product Management Specialization covers three main areas:

### 1. Machine Learning Foundations for Product Managers

* Machine learning fundamentals
* Supervised and unsupervised learning
* Model evaluation and interpretation
* Common machine learning algorithms
* Deep learning concepts

### 2. Managing Machine Learning Projects

* Identifying opportunities for AI and ML
* Data science process and workflows
* Data collection and preparation
* ML system design decisions
* Model deployment and monitoring

### 3. Human Factors in AI

* Human-centered design
* User experience for AI products
* Privacy and ethical considerations
* Bias, fairness, and responsible AI
* Building trust in AI systems
